# TASA

Website and clickable demo for TASA, a free study planner for children (Sild Growth OÜ).

- `index.html` – website, Estonian
- `en/index.html` – website, English
- `demo/index.html` – clickable demo (all names and tasks are made up; it does not connect to any e-diary)
- `assets/` – shared CSS, logos, demo screenshot

Served by GitHub Pages from `main`. Live: https://mhobesalu.github.io/tasa/ (demo at `/demo/`). Planned domain: tasaplan.ee.
