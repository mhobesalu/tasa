# TASA app: notes for coding agents

Expo (SDK 58) + React Native + TypeScript. One codebase for iPhone and Android, testable in Expo Go.

- Use `npx expo install <pkg>` (with `EXPO_OFFLINE=1` if the Expo API is unreachable) so versions match the SDK.
- Only use libraries that ship in Expo Go until the app moves to EAS development builds.
- Before finishing: `npm run typecheck` and `npm test`.
- Navigation is a simple 3-tab shell in `App.tsx` (Täna, Nädal, Lapsevanem). No Expo Router yet.
- `ios/` and `android/` are generated by EAS; never add them by hand.

## Product rules (decided by Maria; don't break them)

- The child sees only today, one "Tee seda nüüd" card, ~25-minute steps.
- TASA only uses material from the school or the parent. It never generates practice problems, solves, or explains.
- Retake (järeltöö): wrong problem numbers are split over 2–3 days before the retake (5 wrong → 2 + 2 + 1).
- One parent-defined reward (name + unit). A day reward counts only if that day's steps were finished ON that day.
- The parent view is behind a PIN; the child never sees it. No bad-grade nudges to parents.
- Parents can add tasks by hand for teachers who don't use the e-diary.
- Data stays on the phone for now (AsyncStorage). EU-only hosting when a server is added.

## Code map

- `src/planner.ts`: splits assignments into steps and spreads them over days (pure, tested).
- `src/logic.ts`: today's frozen list, day-complete rule, rewards, weekly stats (pure, tested).
- `src/store.tsx`: state, persistence, actions.
- `src/screens/`: Today, Week, Parent, Onboarding.
- `src/components/Celebrate.tsx`: confetti, fireworks, emoji rain, gold star, balloons, toast.
